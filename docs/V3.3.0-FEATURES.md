# Enterprise v3.3.0

## Integrated Tor
- Official Tor Expert Bundle is prepared during the Windows build and packaged with the app.
- One-click CONNECT OVER TOR starts an app-owned hidden Tor process.
- Dedicated SOCKS port is selected automatically.
- Bootstrap progress is reflected in the persistent Tor control.
- Green status appears only after Tor Project exit verification succeeds.
- X traffic is fail-closed while Tor starts or if verification fails.
- DISCONNECT OVER TOR stops the app-owned Tor process and deliberately restores direct routing.
- Existing external Tor on 9050/9150 remains a verified fallback.

## Windows icon repair
- Windows executable, NSIS installer, uninstaller, BrowserWindow, and packaged resources all receive the same multi-resolution ICO.
- BrowserWindow also reapplies the native icon at runtime.

## Project cleanup
- Only one root batch file remains: `INSTALL_WINDOWS.bat`.
- Development startup is `npm run dev`.
