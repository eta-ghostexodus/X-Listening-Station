# Enterprise v3.2.0

Adds an interactive common-follower/following relationship mind map and guarded background collection error handling.

## Relationship mind map
- Radial target/identity graph focused on identities observed across two or more monitored target networks.
- Filter graph by all relationships, common followers, or common following.
- Adjustable visible-identity count.
- Click nodes to focus relationships; double-click identity nodes or use Open X Profile to inspect live profiles.
- Edge colors distinguish follower-of-target from target-follows-identity relationships.

## Background collection hardening
- Automatic sweeps and incremental archive cycles run through a guarded background-task wrapper.
- Background failures are logged to startup.log and surfaced inside the application status banner instead of becoming unexplained asynchronous failures.
- Remote X navigation promises are caught and logged.
- Remote renderer termination/unresponsive events are logged.
- Renderer errors and unhandled rejections are surfaced inside the application notice area.
