# Enterprise v3.1.4 clean rebuild

This release rebuilds the Windows distribution layout from the v3.1.3 enterprise source while preserving the application feature set.

Changes:

- Restored the packaged Electron entry point to `electron/main.cjs`.
- Removed the extra bootstrap startup layer.
- Added packaged renderer and preload presence checks.
- Added preload and renderer-process startup logging.
- Reduced the project root to two user-facing batch files: `INSTALL_WINDOWS.bat` and `START_X_LISTENING_STATION.bat`.
- Moved diagnostic helpers under `scripts/diagnostics`.
- Consolidated Windows packaging into one standard NSIS build flow.
- Corrected incremental archive image collection to respect campaign/target image settings.
- Added a release-layout regression test to prevent installer-script clutter from returning.
